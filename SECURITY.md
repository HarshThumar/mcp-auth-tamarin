# Security and disclosure policy

This repository contains **formal models**, not exploit code.

- Models are validated only against issues that are **already public and fixed** (for example, published GitHub Security Advisories).
- If a model suggests a **new** weakness in a real implementation or in a specification, it is first reported privately: through the affected project's GitHub Security Advisory "Report a vulnerability" form, or its documented security contact. Details are published here only after a fix is available or the maintainers agree.
- Any testing against implementations is done only on locally run instances owned by the tester.

To report a problem with this repository itself, open a private security advisory on this repo.
